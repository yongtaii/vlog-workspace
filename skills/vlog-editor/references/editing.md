# 자연스러운 일상·여행 Vlog 판단 기준

- 장소와 상황을 알려주는 첫 컷을 확보하고, 행동의 흐름과 작은 디테일을 연결한다. 촬영 시각/원본 내 순서를 기본으로 하고 phase 힌트로 필요한 맥락을 보완한다.
- 선명하고 밝은 풍경만 연달아 뽑지 않는다. 인물·활동·이동·먹거리·현장 분위기는 직접 확인한 경우에만 의미를 기록한다. 자동 분석은 의미를 인식하지 않는다.
- 샷 길이는 상한값을 기계적으로 채우기보다 동작 시작/끝과 시선의 흐름을 기준으로 조절한다. 조용한 순간도 맥락에 기여하면 유지한다. 같은 구도·같은 행동의 반복과 실수 구간은 줄인다.
- 기본 전환은 cut. 화려한 전환과 잦은 검정 페이드를 강제하지 않는다. 색보정은 선택적이고 약하게 적용한다. HLG SDR 표시 변환은 지원하며 다른 HDR 형식은 별도로 판단한다.
- 현장음은 상황을 전하는 요소다. 배경음악은 사용 권한이 있는 로컬 파일로만 선택하고 현장음/말소리를 덮지 않게 조절한다. source_volume은 전역, clip.source_volume은 컷별 승수다. 자동 대사 인식/ducking/LUFS 보정은 제공하지 않는다.
- 자막은 짧고 필요한 경우에만 사용한다. 한국어 폰트를 확인하고 문장 길이/줄바꿈을 검토한다. 원본에 없는 발화나 사실을 자동 생성하지 않는다.
- 첫 30초 미리보기와 전체 파일 자동 검증은 최종 미적 품질을 보장하지 않는다. 긴 영상 뒷부분과 수정 지점도 확인한다.

- 첫 타이틀에는 제목과 확인된 촬영 날짜를 표시하고 마지막에는 약 4초의 짧은 엔딩을 기본으로 둔다. 본편의 자연스러운 흐름을 유지하고 현재 작업일을 촬영일로 쓰지 않는다.
